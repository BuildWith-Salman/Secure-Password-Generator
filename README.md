#  Python Password Generator

A command-line Password Generator built using Python that creates random passwords based on user preferences and evaluates their strength.



##  Features

- Generate passwords of any length
- Include uppercase letters (A-Z)
- Include lowercase letters (a-z)
- Include numbers (0-9)
- Include special characters (!@#$%^&*)
- Password strength analysis
- Simple and beginner-friendly interface


##  Technologies Used

- Python 3
- random module
- string module



##  Concepts Used

- Variables
- User Input
- Conditional Statements
- Loops
- Strings
- Random Module
- String Module
- Password Strength Validation
